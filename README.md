# YonaMatch 🧩

Çocuklar için eğitici eşleştirme oyunları. Android (Kotlin/Compose) ve iOS (SwiftUI) native uygulamaları.

## Yapı
- `android/` — Android uygulaması
- `ios/` — iOS uygulaması
- `shared-content/` — platformdan bağımsız seviye JSON dosyaları
- `docs/` — ürün ve teknik plan

## İlk hedef
Hafıza kartları oyununu iki platformda oynanabilir hale getirmek. Diğer beş oyun türü sonraki fazlarda geliştirilecektir.

## Geliştirme
Android: Android Studio'da `android/` klasörünü açın. iOS: Xcode'da `ios/` içindeki Swift Package manifestini açın (iOS app target için Xcode projesi oluşturulması gerekecek).

Çocuk güvenliği: ilk sürümde reklam SDK'sı, hesap veya veri toplama yoktur.
